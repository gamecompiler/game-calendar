사운드 & 오디오

🎙️ 소리 분리 녹음 & 오디오 간편 조절

내 목소리, 게임, 디코 친구 목소리를 깔끔하게 나누고 편하게 조절해요
멀티트랙

내 목소리·게임·디코 소리 따로따로 녹음

내 마이크, 게임 소리, 디스코드 친구 목소리, 배경음악을 각기 다른 트랙으로 따로 녹음해 두어, 나중에 편집할 때 원하는 소리만 키우거나 지울 수 있습니다.

BGM 스마트 브릿지

내 말실수만 잘라내도 게임 소리는 그대로

방송 중 헛기침이나 말실수 구간을 잘라내도 게임 배경음악과 효과음은 뚝 끊기지 않고 자연스럽게 이어집니다.

합방 최적화

합방 멤버별 목소리 크기 자동 맞춤

합방할 때 유독 목소리가 크거나 작은 멤버의 음량을 자동으로 고르게 맞춰주고, 말하는 사람에 맞춰 화면 캐릭터가 통통 튀는 효과도 줄 수 있습니다.

스마트 BGM

영상 길이에 맞춰 배경음악 자연스럽게 마무리

영상 끝에 맞춰 배경음악이 어색하게 뚝 끊기지 않고, 곡의 흐름과 마디에 맞춰 자연스럽게 줄어들며 끝나도록 길이를 맞춰줍니다.

저챗 원격 제어

게임컴에서 송출컴 유튜브뮤직 바로 조작

저챗이나 방송 중에 송출컴까지 마우스를 넘기지 않아도, 게임컴에서 바로 송출컴의 유튜브뮤직 재생·정지·다음 곡·볼륨을 조절할 수 있습니다.

오디오 라우팅

복잡한 보이스미터 창 없이 원클릭 음량 조절

어려운 보이스미터 화면을 매번 열 필요 없이, CastEdit 버튼 하나로 방송용 마이크와 디코 마이크를 따로 끄고 켜며 노래방 반주도 바로 보냅니다.

AI 오디오

키보드·마우스 소음 지우고 목소리만 또렷하게

방송이나 녹화 파일에 들어간 시끄러운 키보드 타건음과 마우스 클릭 소리를 AI가 깔끔하게 지우고 내 목소리만 선명하게 살려줍니다.

스트림덱 & 매크로

🕹️ 스트림덱 버튼 하나로 모든 방송 조작

복잡한 플러그인 설치 없이 버튼 한 번으로 투컴·OBS·게임 캡처를 한 번에
허브 단일화

스트림덱 플러그인 여러 개 깔 필요 없는 통합 연결

여러 개의 외부 플러그인을 따로 설치하고 설정할 필요 없이, 스트림덱 기본 기능만으로 CastEdit의 모든 제어 기능을 바로 연결해 쓸 수 있습니다.

투컴 제어

게임컴 스트림덱으로 송출컴 OBS까지 한 번에 조작

게임컴 앞에 앉아서 스트림덱 버튼만 누르면 송출컴의 OBS 화면 전환, 마이크 음소거, 하이라이트 챕터 표시가 실시간으로 실행됩니다.

게임 자동 감지

버튼 한 번으로 UI 숨기고 고화질 게임 스샷 찍기

지금 플레이 중인 게임을 알아서 파악해 게임 UI를 잠시 숨긴 뒤 깨끗한 스샷을 찍고 다시 UI를 켜주며, 게임별 폴더에 예쁘게 정리해 줍니다.

원클릭 전환

버튼 하나로 1초 만에 노래방 모드 켜기

노래 부르고 싶을 때 버튼 한 번만 누르면 내 목소리에 에코가 들어가고, 게임컴에서 트는 반주 소리가 디코 친구들에게도 바로 들립니다.

생성기 내장

어려운 명령어 몰라도 클릭 한 번으로 버튼 만들기

복잡한 명령어를 외울 필요 없이 앱 메뉴에서 원하는 기능을 고르기만 하면 스트림덱에 바로 붙여넣을 수 있게 복사해 줍니다.

다이얼 조작

다이얼 돌려서 마이크·게임·BGM 소리 미세 조절

스트림덱 플러스의 다이얼을 돌리면 마이크, 게임 소리, 배경음악 크기를 방송 도중에도 손쉽게 조금씩 키우거나 줄일 수 있습니다.

생방 운영 자동화

⚡ 매일 반복되는 생방 준비와 뒷정리 자동화

방제 변경부터 파일 이동, 썸네일, 일정표 공지, 다시보기 업로드까지
치지직 직결

OBS 화면만 바꾸면 치지직 게임·방제 자동 변경

다른 게임으로 넘어갈 때마다 치지직 스튜디오에 들어가서 일일이 수정할 필요 없이, OBS 장면만 바꾸면 카테고리와 방제가 알아서 바뀝니다.

투컴 자동화

방송 끝나면 송출컴 녹화 파일 알아서 가져오기

방송을 끄는 순간 송출컴에 저장된 대용량 녹화 파일을 편집컴 폴더로 깨짐 없이 안전하게 자동으로 옮겨옵니다.

1초 완성

게임 로고·회차 넣어서 1초 만에 썸네일 완성

미리 맞춰둔 게임 로고, 다시보기 도장, 회차 번호 틀에 배경 이미지와 제목만 넣으면 깔끔한 고화질 썸네일이 1초 만에 나옵니다.

공지 동시 배포

노션 일정으로 주간 시간표 만들고 카페·디코 동시 공지

노션에 적어둔 이번 주 방송 일정을 불러와 깔끔한 주간 일정표 이미지로 만들고, 네이버 카페·디스코드·유튜브 커뮤니티에 한 번에 올립니다.

종료 후 마법사

다시보기 파일 이름 정리부터 유튜브 업로드까지 원클릭

방송이 끝난 뒤 파일 이름을 날짜와 회차에 맞춰 예쁘게 바꾸고, 다시보기 유튜브 채널의 해당 재생목록에 예약 업로드까지 한 번에 끝냅니다.

보안 보호

내 계정 정보와 방송 키 안전하게 암호화 보관

유튜브나 치지직 연동 정보, 디스코드 주소 같은 민감한 키 값을 윈도우 보안 저장소에 안전하게 암호화해서 보관합니다.

영상 편집 & AI

🎬 긴 방송 영상도 빠르고 쉽게 편집하기

AI 받아쓰기 자막 컷부터 하이라이트 찾기, 세로 쇼츠 만들기까지
작업 공간

단계별로 딱 맞춘 4가지 편집 화면

긴 영상 크게 자르기(F1), 세밀한 컷과 자막(F2), 효과 넣기(F3), 영상 뽑기(F4)까지 작업 순서에 맞춰 화면이 딱 맞게 바뀝니다.

로컬 AI

AI가 내 방송 말소리 알아서 자막으로 받아쓰기

몇 시간짜리 긴 방송도 내 컴퓨터 그래픽카드를 활용해 AI가 빠르게 말소리를 받아적고, 어려운 게임 고유명사도 사전에 맞춰 정확히 적어줍니다.

혁신적 편집

생성된 자막을 보면서 글자 지우듯 쉽게 컷 편집

어려운 소리 파형 그래프를 눈 빠지게 볼 필요 없이, AI가 뽑아준 자막을 읽으면서 필요 없는 문장에 Del 키만 누르면 영상이 바로 잘립니다.

스마트 탐지

어..., 음... 헛말과 빈 침묵 구간 한 번에 날리기

말 사이사이에 들어간 긴 침묵이나 "어...", "음..." 같은 추임새 구간을 프로그램이 알아서 찾아내어 한 번에 정리할 수 있게 해줍니다.

토큰 0원

채팅 폭발 구간과 !클립 명장면 자동으로 찾기

추가 비용 없이 방송 중 채팅이 터진 순간, 내가 크게 웃거나 소리친 순간, 시청자가 !클립을 친 명장면을 자동으로 짚어줍니다.

숏폼 특화

세로 쇼츠 3분할 제작 & 3분 길이 자동 체크

게임 화면과 채팅창을 위아래로 예쁘게 쌓는 세로 쇼츠 틀을 제공하고, 쇼츠 제한 시간(3분)이 넘지 않게 경고해 주며 쇼츠만 모아서 업로드합니다.

전문 편집

전문 편집기 수준의 타임라인과 버벅임 없는 재생

여러 겹의 영상과 자막 트랙, 부드러운 화면 이동 효과는 물론이고 몇 시간짜리 고화질 원본 영상도 버벅임 없이 가볍게 재생하며 편집합니다.

특화 방송 연출

🎭 낭독회·설명회 등 특별한 방송 콘텐츠 연출

시청자와 함께 보는 낭독회 화면부터 게임 대사창 피하기까지
웹 인터랙션

시청자 화면에서도 같이 넘어가는 발표 슬라이드

스토리 설명회나 토론회를 할 때 내가 슬라이드를 넘기면 시청자가 열어둔 웹페이지 화면도 똑같이 넘어가서 훨씬 몰입감 있는 진행이 가능합니다.

낭독 방송

글만 넣으면 미연시 게임 화면처럼 바뀌는 낭독회

소설이나 괴담 대본 글만 붙여넣으면 캐릭터, 배경, 대사창, 효과음을 자동으로 나눠서 진짜 미연시 게임 같은 낭독 화면으로 만들어 줍니다.

AI 배역

합방 멤버들에게 대사 배역 자동으로 나눠주기

여러 명이 함께 낭독 방송을 할 때 등장인물 성별과 대사량을 분석해서 참여 멤버들에게 공평하게 배역을 자동으로 배정해 줍니다.

실시간 합방

합방 멤버들과 웹으로 똑같은 대본 보며 실시간 낭독

합방에 참여한 동료들이 각자 인터넷 창으로 똑같은 게임 화면과 대본을 동시에 보면서 어긋남 없이 호흡을 맞춰 낭독할 수 있습니다.

자막 지능

게임 속 대사창을 가리지 않게 편집 자막 자동 이동

스토리 게임 편집할 때 게임 자체 대사창이 뜨는 구간만 알아서 피해, 내 편집 자막을 화면 위쪽으로 스르륵 옮겨주어 자막이 겹치지 않습니다.

보안 모자이크

움직이는 개인정보나 채팅창 자유롭게 따라가며 가리기

네모나 동그라미뿐 아니라 원하는 모양대로 모자이크 영역을 그리고, 화면에서 움직이거나 크기가 변하는 대상도 끝까지 따라가며 가려줍니다.

Comparison

일반 편집 툴 vs CastEdit 방송 통합 툴킷

방송 시작 전 설정부터 송출, 종료 후 유튜브 아카이빙까지, 비교할 수 없는 효율을 제공합니다.

구분 일반 편집 툴 (프리미어, 다빈치 등) ✨ CastEdit 데스크톱 툴킷
치지직 카테고리 변경 ✕ 지원 안 함 (스튜디오 웹 열고 매번 수동 변경) ✓ OBS 장면 전환 시 공식 API 실시간 자동 변경
투컴 녹화 파일 이동 ✕ 수동 작업 (탐색기 공유 폴더 열고 기다렸다 복사) ✓ 방송 종료 감지 즉시 자동 복사 & 해시 무결성 검증
멀티트랙 사운드 제어 ✕ 수동 믹싱 (마이크 컷마다 게임 소리 뚝 끊김) ✓ 솔로 모드 스마트 BGM 브릿지로 게임 소리 매끄럽게 유지
스트림덱 허브 매크로 ✕ 플러그인 3종 필요 (VBAN, Multi-OBS 등 설정 복잡) ✓ 단일 CLI 허브 + 활성 게임 인식 무UI 캡처 매크로
주간 일정표 공지 ✕ 포토샵 제작 (이미지 만들고 카페·디코 따로 작성) ✓ 노션 연동 16:9 카드 생성 & 카페·디코·유튜브 동시 포스팅
