Seamless Pipeline

하나의 프로젝트, 4개의 전문 작업 공간

파일을 변환하고 프로그램을 갈아탈 필요가 없습니다. 단축키 F1부터 F4까지 누르는 것만으로 완벽한 영상이 완성됩니다.

F1

구간 선택

대용량 원본 녹화본에서 방송에 쓸 알짜 구간을 인코딩 없이 무손실로 빠르게 추려냅니다.

  • LosslessCut 수준의 0초 분할
  • 디스크 용량을 아끼는 원본 비파괴 방식
  • 게임 소리 처리 모드 (솔로/내레이션/합방)
F2

정밀 컷 & 자막

로컬 Whisper 엔진이 생성한 자막을 읽으며, 대본을 다듬듯 텍스트를 지워 영상을 정밀하게 자릅니다.

  • Delete 키 하나로 대사·영상 동시 삭제
  • 어/음 헛말, 말더듬, 침묵 자동 감지
  • Subtitle Edit 단축키 완벽 호환
F3

시각 효과

재생 중인 화면 그대로 효과를 얹고 확인합니다. 키프레임과 자동 추적 모자이크를 지원합니다.

  • 펀치 줌, 카메라 무빙, 화이트 플래시
  • 자유 모양 모자이크 & 피사체 추적
  • 게임 대사창 인식 자막 회피
F4

내보내기 & 숏폼

롱폼 영상 분할과 2분 59초 쇼츠를 한 타임라인에서 동시에 뽑아 유튜브로 직결합니다.

  • 세로 3분할 쇼츠 템플릿 원클릭 적용
  • 치지직 !클립 채팅 연동 마커
  • 유튜브 예약 공개 및 메타데이터 전송
Built for Streamers

스트리머의 고충을 누구보다 잘 아는 기능들

시중의 범용 편집 툴로는 해결하기 어려웠던 인터넷 방송 특유의 워크플로우를 완벽하게 해결합니다.

🎙️

멀티트랙 오디오 독립 제어

마이크를 잘라내도 게임 BGM이나 디스코드 대화는 끊김 없이 이어집니다. T1~T5 스템 오디오 녹화본의 특성을 살려 매끄러운 오디오 전환을 보장합니다.

📝

문서형 대본 편집 (Text-Cut)

타임라인 파형을 보며 자르는 대신, 워드 문서처럼 자막 텍스트를 읽으며 불필요한 문장을 Delete 키로 지우세요. 영상과 오디오가 마법처럼 함께 정리됩니다.

📱

원클릭 세로 쇼츠 재배치

캠, 게임 화면, 실시간 채팅창을 각각 영역 지정해 9:16 세로 화면에 자유롭게 배치하세요. 2분 59초 길이 초과 경고와 템플릿 저장 기능으로 쇼츠 제작이 5분 만에 끝납니다.

🧠

비용 0원 로컬 지능형 탐지

비싼 클라우드 AI 토큰을 결제할 필요가 없습니다. 로컬 엔진이 채팅 폭발 지점, 시청자 웃음 반응, 오디오 피크를 분석해 하이라이트 구간을 자동으로 추천합니다.

👥

디스코드 합방 완벽 지원

디스코드 통화자마다 목소리 크기가 달라 고생하셨나요? 화자별 음량 자동 정규화(Normalizer), 게스트 전용 자막 색상, 말할 때 반응하는 캐릭터 오버레이까지 기본 제공합니다.

🚀

방송 운영(Ops) 통합 허브

송출컴과 게임컴 동기화, 스트림덱 원클릭 핫키, 치지직 카테고리/제목 실시간 변경, 낭독회 웹 연동까지 방송 송출과 사후 편집을 하나의 생태계로 묶습니다.

Why CastEdit

기존 5단계 편집 방식 vs CastEdit

여러 프로그램을 번갈아 가며 낭비되던 시간과 저장 공간을 획기적으로 줄여드립니다.

비교 항목 기존 방식 (LosslessCut + Premiere + etc.) ✨ CastEdit (올인원)
필요한 프로그램 ✕ 4~5개 (LosslessCut, Premiere, Subtitle Edit, Izotope 등) ✓ 단 1개의 데스크톱 앱
중간 생성 파일 용량 ✕ 수십~수백 GB (구간별 인코딩본, 프록시, 캐시 등) ✓ 0 Byte (원본 비파괴 메타데이터 방식)
자막과 컷 연동 ✕ 분리됨 (컷 편집 후 자막 싱크가 틀어져 재작업 빈번) ✓ 100% 동기화 (자막 지우면 영상 즉시 컷)
멀티트랙 BGM 처리 ✕ 수동 페이드 (마이크 컷마다 게임 소리 잘려 수동 조절) ✓ 스마트 브릿지 (마이크 컷과 무관하게 BGM 지속)
유튜브 쇼츠 제작 ✕ 새 프로젝트 생성 (타임라인 새로 파서 3분할 수동 배치) ✓ 원클릭 동시 추출 (롱폼 컷 기반 9:16 자동 생성)
AI 분석 비용 ✕ 매월 정기 구독료 (클라우드 API 토큰 비용 지속 발생) ✓ 100% 무료 (로컬 Whisper & 로컬 탐지 엔진)
