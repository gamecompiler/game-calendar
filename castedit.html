All-In-One Toolkit

방송 준비부터 송출·정리·편집까지, 모든 실전 기능

사운드 제어, 스트림덱 매크로, 데일리 생방 운영, AI 편집, 특화 컨텐츠까지 스트리머가 매일 쓰는 모든 기능을 하나도 빠짐없이 담았습니다.

사운드 & 오디오

🎙️ 사운드 제어 & 멀티트랙 라우팅 엔진

마이크·게임·디코·알림·BGM 완전 분리 및 실시간 원격 조작
멀티트랙

T1~T5 멀티트랙 무손실 분리 녹화

마이크(T1), 게임 사운드(T2), 디스코드 손님(T3), 시스템 알림(T4), BGM(T5)을 무손실 개별 트랙으로 완벽히 분리 녹화해 편집 시 필요한 소리만 정밀 제어합니다.

BGM 스마트 브릿지

솔로 내레이션 모드 (게임 소리 유지)

말실수나 불필요한 마이크 구간을 잘라내도 게임 BGM과 효과음은 끊김 없이 자연스럽게 이어 붙여 오디오 공백이나 튀는 현상을 원천 방지합니다.

합방 최적화

디스코드 화자별 음량 자동 평준화 (Normalizer)

합방 멤버마다 제각각인 마이크 크기를 자동으로 분석해 균일한 볼륨으로 평준화하고, 말할 때 화면에 캐릭터 바운스 반응을 띄웁니다.

스마트 BGM

배경음악 스마트 마디 마커 & 길이 맞춤

음악이 영상 끝에서 뚝 끊기지 않고 곡의 원래 마디와 엔딩 멜로디에 맞춰 자연스럽게 페이드아웃되도록 곡 길이를 자동으로 조절합니다.

저챗 원격 제어

송출컴 유튜브뮤직 원격 제어 (YTM-Remote)

저챗 방송 중 게임컴에서 송출컴 크롬의 유튜브뮤직을 HTTP 8787 포트로 재생, 정지, 다음 곡, 볼륨 조절까지 딜레이 없이 원격 조작합니다.

오디오 라우팅

Voicemeeter 원격 API 직결 제어

OBS 송출용 마이크와 디스코드 통화용 마이크를 원클릭으로 분리 토글하고, 게임컴 노래방 반주를 디스코드로 즉시 라우팅합니다.

사적 알림 차단

송출컴 사운드 레인 분리 (Not Stream)

카카오톡, 라인, 윈도우 사적 시스템 알림 소리를 방송 송출과 녹화에서 원천 차단하여 방송 사고 위험을 제로로 만듭니다.

AI 오디오

AI 목소리 복원 & 노이즈 캔슬링

작은 로컬 딥러닝 모델을 내장하여 키보드 타건음, 마우스 클릭음, 주변 소음을 제거하고 목소리 톤을 또렷하게 복원합니다.

스트림덱 & 매크로

🕹️ 스트림덱 단일 허브 & 크로스-PC 매크로

외부 플러그인 Zero, 단일 CLI와 게임별 자동 인식 핫키
허브 단일화

플러그인 3종을 하나로 (CastEdit 스트림덱 허브)

VBANDeck, Multi-OBS, WebRequests 플러그인을 깔 필요 없이, CastEdit 단일 실행 파일 명령(CastEdit.exe deck <기능>) 하나로 통합 호출합니다.

투컴 제어

게임컴에서 송출컴 OBS·사운드 완벽 제어

게임컴 스트림덱 버튼 하나로 송출컴 OBS 장면 전환, 소스 토글, 마이크 음소거, 녹화 챕터 마커 생성을 실시간 원격 실행합니다.

게임 자동 감지

활성 게임 인식 매크로 & 무손실 스크린샷

현재 실행 중인 게임을 자동으로 판별해 인게임 UI 숨김 → 스크린샷 캡처 → UI 복원 매크로를 실행하고 게임별 전용 폴더에 자동 분류합니다.

원클릭 전환

원클릭 라이브 노래 모드 전환

버튼 하나로 목소리에 감성 보컬 리버브를 켜고, 게임컴 노래방 반주를 디스코드 멤버에게 즉시 들려주는 노래 모드로 전환합니다.

생성기 내장

스트림덱 버튼 코드 원클릭 생성기

앱 메뉴(도구 → 스트림덱 버튼 만들기)에서 원하는 기능을 선택하면 스트림덱에 바로 붙여넣을 수 있는 실행 명령어를 즉시 클립보드에 복사합니다.

다이얼 조작

스트림덱 플러스 다이얼 볼륨 정밀 조절

스트림덱 로터리 다이얼을 돌려 마이크 볼륨, 인게임 소리, 배경음악 크기를 ±2dB 단위로 세밀하게 조절합니다.

생방 운영 자동화

⚡ 데일리 생방송 운영 도구 (Stream Ops)

치지직 카테고리 연동, 투컴 녹화본 이동, 썸네일·일정표 생산
치지직 직결

OBS 장면 연동 치지직 카테고리 자동 변경

방송 중 OBS에서 게임 장면으로 전환하면 치지직 공식 API를 통해 방송 카테고리, 제목, 태그가 즉시 자동 변경되어 수동 변경이 필요 없습니다.

투컴 자동화

송출컴 녹화본 자동 이동 (SMB 동기화)

방송 종료를 OBS WebSocket으로 감지하는 즉시, 송출 PC의 원본 녹화 파일을 편집 PC의 보관 폴더로 백그라운드 복사하고 표본 해시로 무결성을 검증합니다.

1초 완성

템플릿 기반 썸네일 간편 생산기

게임별 로고, 다시보기 도장, 회차 번호(⑦)를 조합해 배경과 제목만 넣으면 16:9 고화질 썸네일(1280×720 PNG)이 1초 만에 완성됩니다.

노션 기반 주간 일정표 & 커뮤니티 원클릭 게시

노션 방송 일정 DB에서 한 주간 일정을 읽어 16:9 주간 일정표 카드를 렌더링하고, 네이버 카페, 디스코드 웹후크, 유튜브 커뮤니티로 동시 공지합니다.

종료 후 마법사

방송 정리 마법사 (Stream Wrapup)

방송 종료 후 원본 파일명을 규칙대로 일괄 정리하고(예: 채널명 26.11.13 게임명 다시보기 ①.mp4), 다시보기 유튜브 채널로 재생목록·예약 공개 자동 업로드를 진행합니다.

보안 보호

Windows 자격 증명 관리자로 API 토큰 보호

유튜브 OAuth, 치지직 API 토큰, 디스코드 웹후크 주소 등 민감 정보를 평문 파일이 아닌 Windows Credential Manager에 안전하게 암호화 보관합니다.

영상 편집 & AI

🎬 전문 영상 편집 & AI 자동화

F1~F4 작업 공간, 로컬 Whisper 자막 컷, 숏폼 3분할, 하이라이트 탐지
작업 공간

F1~F4 작업 공간 분리 워크플로우

대구간 선택(F1), 정밀 컷 & 자막(F2), 세부 효과(F3), 내보내기(F4)로 분리되어 편집 단계별로 최적화된 화면 배치와 도구를 제공합니다.

로컬 AI

Whisper AI 로컬 음성인식 받아쓰기

NVIDIA GPU 가속으로 몇 시간짜리 방송 음성을 자막으로 빠르게 변환하며, 고유명사 사전 교정 기능으로 게임 용어를 오타 없이 처리합니다.

혁신적 편집

자막 기반 말 단위 컷 & 문서형 대본 편집

복잡한 파형 대신 자막 텍스트나 문서형 대본을 보며 Del 키를 누르면 말 단위로 영상이 즉시 잘려 나갑니다.

스마트 탐지

헛말·침묵 자동 탐지 및 무음 구간 일괄 컷

"어", "음" 같은 불필요한 추임새, 말 반복, 어색한 긴 침묵 구간을 앱이 스스로 탐지하여 일괄 정리 후보로 제안합니다.

토큰 0원

로컬 하이라이트 탐지 (!클립 연동)

API 비용 없이 채팅 폭발 지점, 오디오 데시벨 피크, 웃음소리, 시청자 !클립 명령어를 분석해 쇼츠와 하이라이트 명장면을 자동으로 짚어냅니다.

숏폼 특화

숏폼 3분할 캔버스 & 2분 59초 초과 경고

캠+게임+채팅 3분할 템플릿으로 세로 쇼츠를 간편 배치하고, 쇼츠 한도(3분)에 맞춘 2분 59초 초과 알림 및 숏폼만 일괄 예약 업로드를 지원합니다.

전문 편집

프리미어급 전문 타임라인 & 가벼운 프록시

잔물결 삭제, 롤링/리플 다듬기, J컷/L컷, 멀티 비디오 트랙(V1~V4), 키프레임 모션, 장시간 녹화도 버벅임 없는 libmpv 프록시 재생을 지원합니다.

특화 방송 연출

🎭 특화 컨텐츠 & 낭독회 비주얼 노벨 엔진

인터랙티브 웹 슬라이드, 괴담/웹소설 낭독회 엔진, 대사창 자막 회피
웹 인터랙션

설명회·토론회용 인터랙티브 웹 슬라이드

방송 진행자가 웹 슬라이드를 넘기면 시청자 브라우저에서도 같은 슬라이드가 실시간으로 따라 넘어가며 참여 몰입도를 극대화합니다.

낭독 방송

텍스트-비주얼 노벨 낭독 엔진

웹소설이나 괴담 텍스트를 넣으면 화자, 배경, 장면, 효과음 연출을 자동 분할하여 한 편의 비주얼 노벨 게임 화면으로 변환합니다.

AI 배역

AI 배역 & 지문 자동 분배

등장인물의 성별과 대사 분량을 정밀 분석해 합방 참여자들에게 균형 있게 배역과 지문을 자동 배분합니다.

실시간 합방

낭독회 웹 동시 송출 (브라우저 동기화)

참여 멤버들이 각자의 브라우저로 같은 비주얼 노벨 화면과 전체 대본을 보며 실시간 합방 낭독을 진행할 수 있습니다.

자막 지능

게임 대사창 영역 감지 자막 자동 회피

인게임 대사창 위치를 지정하면 게임 대사가 출력되는 구간 동안 편집 자막이 화면 상단으로 자동 이동해 게임 대사를 가리지 않습니다.

보안 모자이크

키프레임 자유 다각형 모자이크 자동 추적

사각·타원뿐 아니라 자유로운 다각형 모양으로 모자이크를 그리고, 회전하거나 크기가 바뀌는 대상을 Ctrl+Alt+M으로 자동 추적 가림 처리합니다.

Comparison

일반 편집 툴 vs CastEdit 방송 통합 툴킷

방송 시작 전 설정부터 송출, 종료 후 유튜브 아카이빙까지, 비교할 수 없는 효율을 제공합니다.

구분 일반 편집 툴 (프리미어, 다빈치 등) ✨ CastEdit 데스크톱 툴킷
치지직 카테고리 변경 ✕ 지원 안 함 (스튜디오 웹 열고 매번 수동 변경) ✓ OBS 장면 전환 시 공식 API 실시간 자동 변경
투컴 녹화 파일 이동 ✕ 수동 작업 (탐색기 공유 폴더 열고 기다렸다 복사) ✓ 방송 종료 감지 즉시 자동 복사 & 해시 무결성 검증
멀티트랙 사운드 제어 ✕ 수동 믹싱 (마이크 컷마다 게임 소리 뚝 끊김) ✓ 솔로 모드 스마트 BGM 브릿지로 게임 소리 매끄럽게 유지
스트림덱 허브 매크로 ✕ 플러그인 3종 필요 (VBAN, Multi-OBS 등 설정 복잡) ✓ 단일 CLI 허브 + 활성 게임 인식 무UI 캡처 매크로
주간 일정표 공지 ✕ 포토샵 제작 (이미지 만들고 카페·디코 따로 작성) ✓ 노션 연동 16:9 카드 생성 & 카페·디코·유튜브 동시 포스팅
다시보기 썸네일 ✕ 매번 디자인 (외주 템플릿에서 텍스트 수동 배치) ✓ 게임별 로고 + 도장 + 회차 템플릿으로 1초 만에 자동 생성
다시보기 유튜브 업로드 ✕ 수동 렌더 & 업로드 (파일 옮기고 유튜브에서 설정) ✓ 정리 마법사로 날짜 규칙 명명 & 재생목록·예약 공개 직결
자막 기반 컷 편집 ✕ 오디오 파형 수동 컷 (시간 과다 소요) ✓ Whisper 자막 보며 Del 키 하나로 말 단위 즉시 컷
쇼츠 및 하이라이트 탐지 ✕ 전체 영상 수동 다시보기 ✓ 채팅 !클립 및 오디오 피크 기반 로컬 하이라이트 자동 탐지
